Schema DevTools — Privacy Policy

Last updated: August 2026

Summary

Schema DevTools does not collect, store, or transmit your personal data or browsing history. All schema analysis happens locally on your device while Chrome DevTools is open.

Data processing

The extension reads page content only through Chrome DevTools APIs (chrome.devtools.inspectedWindow.eval) when you have DevTools open on a tab. Extracted markup is processed in memory to produce validation results and scores. SERP previews do not load page-provided images. Nothing is uploaded to our servers — we do not operate any servers for this extension.

External links

If you click Rich Results Test or Schema Markup Validator, your browser opens Google or Schema.org with the current page URL as a parameter. That request goes directly from your browser to those services; we do not receive it.

Permissions

Schema DevTools requests no host permissions and no optional permissions. It registers a DevTools page only.

Telemetry

We do not use analytics, crash reporting, or any form of telemetry.

Contact

Questions about this policy can be directed to the extension publisher via the Chrome Web Store listing.
